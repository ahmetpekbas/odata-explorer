# R4 — Query URL builder

[Roadmap](README.md) · [Plan](../PLAN.md)

- **Status:** post-v1. When it is picked up, split each item into tasks sized as described in the [roadmap](README.md#how-to-use-this-roadmap).
- **Needs:** v1

- [ ] **R4.1** A form tied to an entity set: `$select`, `$expand` (nested), `$orderby`, `$top`/`$skip`,
  `$count`, with path pickers driven by the model.
- [ ] **R4.2** `$filter` authoring with property- and type-aware operators and literal formatting.
- [ ] **R4.3** Checks against Capabilities restrictions (non-filterable or non-sortable properties,
  unsupported expands), with warnings inline.
- [ ] **R4.4** Copy the URL, with an optional base-URL field. The tool does not execute requests.
